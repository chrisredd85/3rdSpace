# SEO Implementation Guide

This document outlines the SEO and metadata implementation for the 3rdSpace platform.

## Overview

The platform includes comprehensive SEO optimization with:
- Default metadata in root layout
- Page-specific metadata for all routes
- Dynamic metadata for venue/event pages
- Structured data (JSON-LD) for rich snippets
- Sitemap generation
- Robots.txt configuration
- Open Graph and Twitter Card support

## Root Layout Metadata

**File**: `/app/layout.tsx`

- **Title Template**: `"%s | 3rdSpace"` - All pages automatically get the 3rdSpace suffix
- **Default Description**: "Bay Area's leading B2B event marketplace..."
- **Open Graph**: Full OG tags with default image
- **Twitter Card**: Summary large image card
- **Robots**: Optimized for search engines
- **Organization Schema**: JSON-LD structured data in `<head>`

## Page-Specific Metadata

### Dashboard Pages

#### Builder Dashboard
- **File**: `/app/(dashboard)/builder/layout.tsx`
- **Title**: "Dashboard | 3rdSpace"
- **Description**: "Manage your events, find venues and vendors..."

#### Venue Dashboard
- **File**: `/app/(dashboard)/venue/layout.tsx`
- **Title**: "Venue Dashboard | 3rdSpace"
- **Description**: "Manage your venue listings, booking requests..."

#### Vendor Dashboard
- **File**: `/app/(dashboard)/vendor/layout.tsx`
- **Title**: "Vendor Dashboard | 3rdSpace"
- **Description**: "Manage your service listings, booking requests..."

### Dynamic Metadata

#### Event Pages
- **File**: `/app/(dashboard)/builder/event/[eventId]/layout.tsx`
- **Function**: `generateMetadata()`
- **Features**:
  - Fetches event data from Supabase
  - Uses event title as page title
  - Includes event description
  - Adds event date to description
  - Open Graph image support
  - Twitter Card support

## Structured Data (JSON-LD)

### Organization Schema
- **Location**: Root layout `<head>`
- **Type**: Organization
- **Includes**: Name, URL, logo, description, contact info, social links

### Event Schema
- **Component**: `StructuredData` component
- **Location**: Event detail pages
- **Type**: Event
- **Includes**: Name, description, start/end dates, location, organizer, status

### LocalBusiness Schema
- **Component**: `StructuredData` component
- **Type**: LocalBusiness
- **For**: Venue and vendor listings
- **Includes**: Name, address, phone, image, price range

### Utilities
- **File**: `/lib/utils/seo.ts`
- **Functions**:
  - `generateOrganizationSchema()`
  - `generateEventSchema()`
  - `generateLocalBusinessSchema()`
  - `generateBreadcrumbSchema()`

## Sitemap

**File**: `/app/sitemap.ts`

### Included Pages
- Static pages (home, login, signup)
- Public venues (verified and active)
- Public vendors (verified and active)
- Public events (confirmed/in_progress)

### Features
- Dynamic generation from Supabase
- Update frequency hints
- Priority levels
- Last modified dates

### Access
- URL: `https://3rdspace.com/sitemap.xml`
- Automatically generated by Next.js

## Robots.txt

**File**: `/app/robots.ts`

### Rules
- **Allow**: All public pages
- **Disallow**:
  - `/api/` - API routes
  - `/builder/` - Builder dashboard
  - `/venue/` - Venue dashboard
  - `/vendor/` - Vendor dashboard
  - `/admin/` - Admin pages
  - `/_next/` - Next.js internals
  - `/auth/` - Auth routes

### Sitemap Reference
- Links to `/sitemap.xml`

### Access
- URL: `https://3rdspace.com/robots.txt`
- Automatically generated by Next.js

## Open Graph Images

### Default Image
- **Path**: `/public/og-default.png`
- **Size**: 1200x630px (recommended)
- **Usage**: Default for all pages without specific OG images

### Dynamic Images (Future)
- Venue pages: `/og/venues/[venueId].png`
- Event pages: `/og/events/[eventId].png`
- Generated via API route or static generation

## Semantic HTML

### Best Practices Implemented

1. **Heading Hierarchy**
   - `<h1>` - Main page title (one per page)
   - `<h2>` - Section titles
   - `<h3>` - Subsection titles
   - Proper nesting (no skipping levels)

2. **Semantic Tags**
   - `<main>` - Main content area
   - `<nav>` - Navigation
   - `<article>` - Event/venue listings
   - `<section>` - Content sections
   - `<header>` - Page headers
   - `<footer>` - Page footers

3. **Image Alt Text**
   - All images have descriptive alt text
   - Venue/vendor photos include context
   - Decorative images use empty alt=""

4. **Link Text**
   - Descriptive link text (not "click here")
   - Context-aware labels
   - Accessible to screen readers

## Environment Variables

Add to `.env.local`:

```env

```

## Verification Codes

Add verification codes in `/app/layout.tsx`:

```typescript
verification: {
  google: "your-google-verification-code",
  yandex: "your-yandex-verification-code",
}
```

## Testing SEO

### Tools
1. **Google Search Console**
   - Submit sitemap
   - Monitor indexing
   - Check for errors

2. **Rich Results Test**
   - Test structured data: https://search.google.com/test/rich-results
   - Validate JSON-LD schemas

3. **Facebook Sharing Debugger**
   - Test Open Graph: https://developers.facebook.com/tools/debug/
   - Clear cache if needed

4. **Twitter Card Validator**
   - Test Twitter Cards: https://cards-dev.twitter.com/validator

5. **Lighthouse**
   - Run SEO audit
   - Check best practices
